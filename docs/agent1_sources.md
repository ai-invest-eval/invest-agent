# Agent 1 탐색 소스

Agent 1은 `src/agents/agent1_search.py` 하나로 구현한다.

| 소스 | 검색 도메인 | 역할 |
| --- | --- | --- |
| 스타트업레시피 | startuprecipe.co.kr | 국내 AI 신약개발 기업·투자 기사 |
| Cure Funding Tracker | wewillcure.com | AI 신약개발 투자 트래커 |
| YC 기업 디렉터리 | ycombinator.com | AI 신약개발 스타트업 소개 |

- 소스별 Tavily 검색 1회로 공개 페이지를 수집한다. 사이트 자체 API나 전체 DB 수집이 아니다.
- 소스 검색은 도메인을 제한하며 Hacker News 댓글 페이지는 제외한다.
- 기업별 추가 검색 1회는 도메인 제한 없이 자격 근거를 찾는다. LLM 판단도 1회뿐이며 재검색·별도 근거 감사는 하지 않는다.
- 검색 계획과 중복 병합은 별도 LLM을 쓰지 않는다. 이름·별칭 정규화로 중복을 제거한다.
- 자격 판단은 AI 신약개발, 비상장, Exit 미완료, 대기업 자회사 아님, Seed~Series C를 확인한다. 원문 근거가 없는 사실은 None이다.
- 해외 소스라고 해외 기업/투자 시장으로 추정하지 않는다. 투자 시장 확인 시에만 F 접미사를 붙인다.
- 모델의 문서 ID·발췌는 실제 본문과 대조한다. 이 검사는 원문의 사실성이나 판단의 의미적 정확성을 보증하지 않는다.
- 긴 본문은 분할해서 기업을 추출하지만 전체 모집단이나 모든 최신 기업 상태를 확인했다고 보장하지 않는다.
- 최대 후보 수의 2배까지만 자격 판단하며 목표 수에 도달하면 멈춘다. 조건 확인 기업이 부족하면 후보가 목표 수보다 적다.
- `app.py --agent 1`로 독립 실행한다. 구 단계별 개발 스크립트는 제거했다.
- 기존 `outputs/discovery`, `outputs/qualification`, `outputs/agent1` 결과는 보존한다.
